# warcraft-clone

Warcraft 1-style RTS clone, browser-based, 3D units via Three.js. Phase 1: a single simple skirmish mission (one map, basic unit movement/combat).

## Quick Start

```bash
./run.sh start
```

See `./run.sh help` for all commands.

## Development

| Command | Description |
|---------|--------------|
| `./run.sh start` | Start all services |
| `./run.sh stop` | Stop all services |
| `./run.sh logs` | Tail logs |
| `./run.sh test` | Run tests |
| `./run.sh shell` | Open shell in main container |
